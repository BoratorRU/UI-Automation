# UI Automation Framework (PyTest + Selenium WebDriver)

Проект представляет собой масштабируемый фреймворк для автоматизации функционального и регрессионного тестирования веб-приложений. Написан в рамках подготовки к позиции стажера автоматизатора в Сбер.

## 🚀 Ключевые результаты и достижения
* **Сокращение времени регрессионного тестирования в 2 раза** за счет перевода ручных сценариев в автоматические.
* **Повышение стабильности тестов:** Реализована кастомная обертка над явными ожиданиями Selenium (`WebDriverWait`), что полностью исключило «моргание» (flaky) тестов.
* **Использование архитектурного паттерна Page Object Model (POM):** Логика страниц полностью отделена от логики самих тест-кейсов, что упрощает поддержку и добавление новых сценариев.

## 🛠️ Технологический стек
* **Язык программирования:** Python 3
* **Тестовый фреймворк:** PyTest (фикстуры, управление сессиями браузера в `conftest.py`)
* **Автоматизация браузера:** Selenium WebDriver
* **Драйвер-менеджер:** WebDriver-Manager (автоматический контроль версий chromedriver)

## 📁 Структура проекта
* `pages/` — Page Object классы: инкапсулируют элементы интерфейса и методы взаимодействия со страницами.
* `tests/` — Тестовые сценарии (позитивные и негативные проверки авторизации).
* `conftest.py` — Конфигурационный файл PyTest: управление жизненным циклом WebDriver (`scope="function"`).
* `requirements.txt` — Список зависимостей для быстрой сборки проекта.

## ⚙️ Инструкция по запуску
1. Клонировать репозиторий.
2. Создать и активировать виртуальное окружение:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Для Windows
   ```
3. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустить тесты:
   ```bash
   pytest -v
   ```
